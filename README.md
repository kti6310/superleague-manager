# Super League Manager

슈퍼리그 18개 구단 중 한 팀의 감독이 되어 조별 리그 + 포스트시즌으로 이뤄진 시즌을 5시즌 동안 치르는 Java(Swing) 축구 감독 게임입니다. Java 17 이상, 외부 라이브러리 없음.

## 실행 방법

| 방법 | 하는 법 | 언제 |
| --- | --- | --- |
| **VS Code** | 이 폴더(`superleague`)를 열고 `F5` 또는 실행 및 디버그(Ctrl+Shift+D)에서 **게임 실행** | 코드를 고쳤을 때 (항상 최신 코드로 실행) |
| **더블클릭** | `게임 실행.vbs` | 그냥 게임만 할 때 (미리 빌드된 `SuperLeague.jar` 실행) |
| **웹 브라우저** | `웹으로 실행.vbs` 또는 VS Code에서 **웹 버전 실행** | 브라우저 창에서 하고 싶을 때 (인터넷 필요) |

VS Code에서 빨간 오류가 남아 있거나 실행이 안 되면: `Ctrl+Shift+P` → **Java: Clean Java Language Server Workspace** → Restart.

명령줄로 직접 빌드할 때:

```bash
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out superleague.Main            # 게임 창
java -cp out superleague.Main --web      # 웹 버전
java -cp out superleague.Main --console  # 터미널 텍스트 모드
jar --create --file SuperLeague.jar --main-class superleague.Main -C out .   # 더블클릭용 jar 다시 만들기
```

| 옵션 | 설명 |
| --- | --- |
| `--web` | 내장 웹 서버를 켜고 브라우저로 실행 |
| `--console` | 터미널 텍스트 모드 |
| `--auto` | 콘솔에서 입력 없이 시즌 끝까지 자동 진행 |
| `--team 18` | `--auto`에서 맡을 구단 번호 (1~18) |
| `--seed 42` | 콘솔 모드에서 같은 선수단·일정·결과 재현 |

## 화면 구성

- **시작 화면**: 18개 구단 카드 중 하나를 골라 감독으로 부임합니다.
- **상단**: 구단명, 진행 라운드·순위·승점, 다음 상대와 상대의 주 전술
- **왼쪽**: 팀 상태(사기·훈련 수준·시설), **다음 상대**(등급·순위·전적·운영·포메이션·팀 지시·스카우트 조언·**예상 선발 11명**, 선수를 누르면 선수 카드), `경기 진행` / `끝까지 자동`
- **경기 운영**(매우 공격적~매우 수비적)은 전술 탭 위쪽, **훈련 강도**는 훈련 탭 > 팀 훈련에 있습니다.
- **포지션 색**: 공격수 빨강 · 미드필더 초록 · 수비수 파랑 · 골키퍼 노랑. 전술판 선수 동그라미(자리 기준), 자리·포지션 글자, 선수단 탭, 선수 선택 목록, 선수 카드에 적용됩니다.
- **선수 카드**: 선수단 탭·훈련 탭에서 선수를 누르거나, 전술 탭에서 선수 이름(또는 후보 줄)을 누르면 뜹니다. 포지션별 능력(예: `ST 190  LW 184`), 신상 정보 아래에 **기술적 능력 · 정신적 능력 · 신체**(1~20, 골키퍼는 골키퍼 능력)와 명성·성격·언론 설명·선수 특성이 나옵니다. 초록 줄은 그 포지션의 핵심 능력, 파란 줄은 중요 능력입니다.
- **날짜 진행 (FM 방식)**: 정규 시즌 27경기일(2026.08.29 ~ 2027.03.20, 겨울 휴식기·주중 경기 2번 포함), 플레이오프 4월 초, 8강 4월, 4강 5월, 결승 2027.05.29(토). 시즌은 2026.08.22에 시작하고, 왼쪽 아래 버튼이 평소에는 **다음 날 ▶**, 경기 당일에는 **경기 진행 ▶**으로 바뀝니다. 위쪽에 오늘 날짜와 다음 경기까지 D-day가 나옵니다.
- **하루 활동**(훈련 탭 > 일정): 날마다 **훈련 / 가벼운 훈련 / 회복 / 휴식** 중 하나를 고릅니다. 기본 계획은 경기 다음 날 회복, 경기 전날 가벼운 훈련, 일요일 휴식, 나머지 훈련입니다. 훈련하는 날에는 이번 주 팀 훈련과 훈련 강도가 적용되고, 휴식할수록 체력은 오르지만 훈련 수준이 떨어집니다. **경기 당일까지 ▶▶**로 한 번에 넘어갈 수 있고, `끝까지 자동`은 정해 둔 계획대로 날짜를 넘깁니다. 상대 팀은 예전처럼 주 단위로 훈련합니다.
- **훈련 탭**
  - 탭 위쪽 버튼으로 **일정 / 팀 훈련 / 개인 훈련** 화면을 바꿉니다.
  - **팀 훈련**(매주 하나, 훈련 강도와 함께 적용): 상대 팀은 균형 훈련을 합니다.

| 분류 | 훈련 | 효과 |
| --- | --- | --- |
| 균형 | 균형 훈련 | 보정 없음 |
| 공격 | 빌드업 패스 / 측면 공격·크로스 | 득점 기대 +3%, 체력 -2 |
| 공격 | 역습 전개 | 득점 기대 +3%, 실점 억제 +1%, 체력 -3 |
| 공격 | 마무리 슈팅 | 득점 기대 +4%, 체력 -2 |
| 수비 | 전방 압박 | 득점 +1%, 실점 억제 +3%, 경기 체력 소모 +1, 체력 -3 |
| 수비 | 수비 라인 조직 | 실점 억제 +4%, 체력 -2 |
| 수비 | 대인 마크 | 실점 억제 +3%, 체력 -2 |
| 세트피스 | 세트피스 공격 / 수비 | 득점 +2% 또는 실점 억제 +2%, 체력 -1 |
| 체력 | 지구력 | 경기 체력 소모 -3, 체력 -4, 훈련 수준 +1 |
| 체력 | 스피드·민첩성 | 득점 +1%, 실점 억제 +1%, 체력 -4, 훈련 수준 +1 |
| 회복·분위기 | 회복 훈련 | 체력 +6, 훈련 수준 -2 |
| 회복·분위기 | 완전 휴식 | 체력 +10, 사기 +3, 훈련 수준 -4 |
| 회복·분위기 | 팀 빌딩 | 사기 +5, 체력 +2, 훈련 수준 -1 |

  - **개인 훈련**(선수마다): 스피드·슛·패스·드리블·수비·피지컬 중 하나에 집중하면 라운드마다 확률로 그 능력이 오르고(젊을수록 잘 오름), 카드의 관련 세부 능력도 같이 오릅니다. **새 포지션 익히기**를 고르면 8점이 모였을 때 보조 포지션으로 추가됩니다(23세 이하 라운드당 2점, 그 외 1점). 결과는 소식 탭에 나옵니다.
- **오른쪽 탭**: 라운드 결과, 전술, 순위표, **경기 일정**(34경기일 전체: 날짜·홈/원정/중립·상대·상대 순위·결과·득점자, 쉬는 라운드와 대진 미정 표시), 선수단, 시즌 기록, 소식
- **팝업**: 경기 중계 창, **조 추첨식**(매 시즌 시작), 정규 시즌 반환점(14경기일) 중간 평가·시즌 종료 평가(보상 선택), 엔딩

## 전술 (전술 탭)

- **포메이션** (13종 + 사용자 지정): 4-4-2, 4-3-3, 4-2-3-1, 3-5-2, 3-4-3, 4-1-4-1, 4-3-3 (홀딩), 4-4-2 다이아몬드, 4-4-1-1, 4-2-2-2, 3-4-2-1, 5-4-1, 5-3-2
- **전술판 점·자유 배치**: 전술판에 선수가 설 수 있는 위치가 흰 점(26곳)으로 찍혀 있습니다.
  - 선수를 **빈 점으로 끌어다 놓으면** 그 위치로 옮겨지고, 포메이션이 **사용자 지정**으로 바뀝니다. 점마다 자리가 정해져 있습니다 (수비 LB·LCB·CB·RCB·RB / 수비형 LWB·LDM·DM·RDM·RWB / 중원 LM·LCM·CM·RCM·RM / 공격형 LW·AM·RW / 처진 공격수 LF·CF·RF / 최전방 LS·ST·RS).
  - 중앙 자리는 왼쪽·오른쪽에 따라 이름이 붙습니다: LCB/RCB, LDM/RDM, LCM/RCM, LS/RS.
  - 끄는 동안 놓을 수 있는 점이 노란색으로 커지고 역할 이름이 보입니다. GK는 옮길 수 없습니다.
  - 다른 포메이션을 골랐다가 다시 **사용자 지정**을 고르면 직접 만든 배치가 그대로 돌아옵니다. 상대 팀은 사용자 지정을 쓰지 않습니다.
- **전술 스타일**: 팀 지시 4개를 한 번에 맞춰 줍니다. 고른 뒤 슬라이더로 더 고치면 "직접 설정"이 됩니다.

| 스타일 | 압박 | 템포 | 라인 | 폭 | 성격 |
| --- | --- | --- | --- | --- | --- |
| 기본 | 3 | 3 | 3 | 3 | 모든 지시 보통 |
| 점유율 축구 | 4 | 2 | 4 | 4 | 천천히 돌리며 높은 위치에서 공을 지킴 |
| 게겐프레싱 | 5 | 5 | 5 | 3 | 높은 압박과 빠른 전개, 체력 소모 큼 |
| 역습 | 2 | 5 | 2 | 3 | 내려서서 막다가 빠르게 역습 |
| 롱볼·측면 | 3 | 4 | 3 | 5 | 넓게 벌려 크로스와 공중볼 공략 |
| 버스 세우기 | 1 | 1 | 1 | 2 | 최대한 내려서서 실점 억제 |

- **선발 11명**: 표의 행이나 경기장의 동그라미를 누르면 그 자리에 들어갈 수 있는 선수 목록이 뜹니다. 이미 다른 자리에 있는 선수를 고르면 두 선수가 자리를 바꿉니다.
  - 선수마다 **주 포지션 + 보조 포지션**이 있습니다 (예: 음바페 `ST, LW`, 벨링엄 `AM, CM`). 주 포지션 100%, 보조 포지션 97%로 뜁니다.
  - **GK 자리에는 GK만** 나옵니다. 나머지 자리는 **실제로 뛸 수 있는 세부 포지션**이면 그룹이 달라도 목록에 나옵니다 (포지션 범용성).
  - 예: LAM 자리 → LM 98%, LW 97%, AM 96%, RM·RW 92%, CF 86%, CM 85% / AM 자리 → CM·CF 92%, 측면 4종 88%, ST 84% / LW 자리 → RW 95%, LM 94%, CF 90%, AM·ST·RM 88%
  - 전혀 맞지 않는 조합(예: CB를 윙어로)은 목록에서 빠집니다. 표는 `model/Versatility.java`에서 고칠 수 있습니다.
  - 선발 표는 **GK → 수비(오른쪽부터) → 미드필더(수비형→중앙→공격형, 오른쪽부터) → 공격수(오른쪽부터)** 순서로 정렬됩니다.
  - 선발 표에 **후보까지 한 표로** 나옵니다. 선발 11명 아래 굵은 선 밑으로 후보가 번호(1, 2, 3…)와 함께 이어집니다. 포지션(GK→DF→MF→FW)·능력 순이고, 부상 선수는 "부상 n경기"로 표시됩니다.
  - **경기장 그림에서 선수를 마우스로 끌어 다른 자리에 놓으면 두 선수 자리가 바뀝니다** (GK 자리는 GK끼리만). 클릭하면 선수 목록이 뜹니다.
  - 목록은 "이 자리에서 낼 수 있는 능력" 순으로 정렬되고, 적합도가 초록(100%)·주황(88% 이상)·빨강으로 표시됩니다.
  - 경기장의 동그라미 테두리: 흰색은 딱 맞는 자리, 주황은 약간 불리, 빨강은 크게 불리합니다.
  - 직접 고르면 "매 경기 자동 선발"이 꺼지고, 그 명단이 다음 경기에도 유지됩니다. 부상자만 자동으로 교체됩니다.
- **팀 지시** (1~5)

| 지시 | 올리면 |
| --- | --- |
| 압박 강도 | 실점 기대 -4%/단계, 체력 소모 +3/단계 (낮추면 실점 +4%/단계, 체력 -1/단계) |
| 템포 | 득점·실점 기대 모두 +3%/단계, 체력 소모 +1/단계 |
| 수비 라인 | 득점 기대 +3%/단계, 실점 기대 +4%/단계 |
| 공격 폭 | 득점 기대 +2%/단계, 공중볼(키) 효과 확대 |

300시즌 시뮬레이션 기준으로 한 가지 설정이 항상 이기지는 않습니다. 강팀은 높은 압박에 템포를 조절할 때, 약팀은 내려서서 버틸 때 성적이 좋았고, 압박 없이 템포만 올리는 식의 엇갈린 설정은 2계단 정도 손해를 봅니다.

상대 팀은 시즌 시작 때 선수단에 가장 맞는 포메이션을 고르고, 주 전술 성향에 맞춰 팀 지시를 정합니다.

## 선수 역할 (전술 탭 "역할" 칸)

선발 표의 **역할** 칸을 누르면 그 자리에서 고를 수 있는 역할과 설명·효과가 나옵니다. 역할은 팀 득점·실점 기대치(한 명당 ±0.5~2%), 골·도움을 누가 기록할지, 경기당 체력 소모에 영향을 줍니다. 기본 역할(각 자리 첫 번째)은 보정이 없습니다.

| 자리 | 역할 | 설명 |
| --- | --- | --- |
| GK | 골키퍼 | 골문을 지키는 데 집중합니다. 가장 안정적인 선택입니다. |
|  | 스위퍼 키퍼 | 라인 뒤 공간을 넓게 커버하고 빌드업에 참여합니다. 공격 전개 +, 실점 위험 +. |
| CB | 중앙 수비수 | 자리를 지키며 안정적으로 막습니다. |
|  | 볼 플레잉 디펜더 | 후방에서 패스로 빌드업을 시작합니다. 공격 +, 수비 -. |
|  | 스토퍼 | 앞으로 나가 상대 공격수를 먼저 끊습니다. 수비 +, 체력 소모 +. |
|  | 커버 수비수 | 한 발 물러서 뒷공간을 커버합니다. 수비 +, 빌드업 -. |
| LB, RB | 풀백 | 공격과 수비를 균형 있게 합니다. |
|  | 공격적 풀백 | 측면을 적극적으로 올라가 크로스를 올립니다. 공격 +, 수비 -, 체력 소모 +. |

## 경기 중계

- `경기 진행`을 누르면 중계 창이 열리고 0분부터 90+추가시간까지 문자 중계가 한 줄씩 올라옵니다.
- **경기장 화면** (실제 경기장 비율 105:68): 선수 22명이 바둑알로 움직입니다. 홈 = 흑돌, 원정 = 백돌, 노란 공 = 볼.
  - 각 팀은 실제 포메이션 위치에서 출발해 공격·수비 상황에 따라 라인을 올리고 내립니다.
  - 슈팅·골·선방 장면에서는 해당 선수가 노란 테두리와 이름으로 표시되고, 공이 골문·골키퍼로 이동합니다.
  - **하프타임에 진영 교체**: 전반엔 홈팀이 오른쪽으로, 후반엔 왼쪽으로 공격합니다.
- 속도 1x / 2x / 4x, `일시정지`/`계속`, `결과 바로 보기`. 골이 나오면 잠깐 멈춥니다.
- **선수 교체** (경기당 최대 5명, 교체 기회 3번): `선수 교체` → 나갈 선수(자리)와 들어갈 선수를 고르고 **교체 목록에 추가**를 반복한 뒤 **교체 확정**을 누르면, 목록의 선수(최대 남은 인원)가 한 번에 교체되고 교체 기회 1번이 쓰입니다.
  - 교체 화면과 경기 화면 오른쪽 **우리 팀 체력** 칸에 선수별 현재 체력이 나옵니다(경기 전 체력 − 뛴 시간만큼의 소모, 75% 이상 초록 · 55% 이상 주황 · 그 아래 빨강).
- **경기 중 체력 반영**: 선발 11명이 남은 시간 동안 평균적으로 얼마나 지칠지 계산해 경기력에 바로 반영합니다(체력 1% 감소 ≈ 경기력 0.6% 감소). 압박을 많이 하는 전술일수록 빨리 지치고, 지친 선수를 교체하면 그 순간부터 팀 경기력이 회복된 상태로 남은 시간이 다시 계산됩니다.
- **승부차기**: 플레이오프·8강·4강 합계가 같거나 결승에서 비기면 실제로 키커를 한 명씩 차게 합니다(슈팅 능력 높은 순, 5명 + 서든데스, 성공률은 키커 슛 능력과 상대 골키퍼에 따라 55~92%). 우리 팀 경기면 승부차기 화면이 떠서 키커 이름 → 잠시 뒤 "골!", "크로스바를 넘겼어요!", "골키퍼 선방!" 같은 결과가 한 명씩 나옵니다.
- **경기 중 전술 변경**: `전술 변경` → 경기 운영(매우 공격적 ~ 매우 수비적)과 팀 스타일(점유율 축구·게겐프레싱·역습 등)을 바꾸면 그 순간부터 남은 시간이 다시 계산됩니다. 횟수 제한은 없고, 경기가 끝나면 경기 전 전술로 돌아갑니다.
  - 들어갈 선수 목록은 그 자리에서 뛸 수 있는 선수만, 기대 능력 순으로 나옵니다 (GK 자리는 GK만).
  - 교체한 순간부터 **남은 시간이 새 라인업으로 다시 시뮬레이션**됩니다. 이미 나온 골·기록은 그대로입니다.
  - 교체로 나간 선수는 다시 들어올 수 없고, 체력 소모는 뛴 시간만큼만 적용됩니다. 경기가 끝나면 선발 라인업은 원래대로 돌아갑니다.
- 자책골이 약 4% 확률로 나옵니다 (득점자 기록에는 "(자책)"으로 표시되고 개인 득점에는 들어가지 않음).
- **라운드 결과 탭**: 시간선 위에 축구공으로 골이 표시됩니다. 홈 골은 선 위, 원정 골은 선 아래에 "시간 + 득점자"가 붙고, **자책골은 빨간 공·빨간 글씨**입니다. `문자 중계 다시 보기`로 다시 볼 수 있습니다.
- `끝까지 자동`일 때는 중계 없이 진행합니다.
- 중계 내용은 실제 경기 결과(득점자·스코어)와 항상 일치합니다.

## 게임 규칙

- **경기력** = 선발 11명의 자리별 능력(포지션·주발 적합도 반영) 평균 × (1 + 사기 보정 + 훈련 보정 + 시설 보정 + 국적 호흡 보정)
  - 사기 −100~+100 → −8%~+8%
  - 훈련 수준 0~100 → −5%~+7% (상한 = 60 + 시설 레벨 × 8)
  - 시설 레벨 1~5 → +1%~+5%
- **훈련 강도**: 강하게 할수록 훈련 수준은 오르지만 사기·체력이 떨어지고 부상 위험이 커집니다.
- **경기 운영 상성**: 공격형 > 밸런스형 > 수비형 > 공격형. 상성에서 이기면 기대 득점 +25%.
- **등급 격차 완화**: 높은 등급 팀은 비기거나 지면 사기가 더 떨어지고, 낮은 등급 팀은 강팀을 잡으면 사기가 더 오릅니다.
- **시즌 진행 방식 (디비전 + 포스트시즌)**
  - 18팀을 9팀씩 **A조·B조**로 나눠, 같은 조와 홈 앤드 어웨이 16경기 + **다른 조 9팀과 한 번씩 9경기**(MLS의 컨퍼런스 간 경기 방식)로 팀당 25경기를 치릅니다. 다른 조와의 경기 결과도 조 순위 승점에 들어갑니다. 경기일 27번 중 같은 조 경기일에 2번은 휴식이고, 세 번째 경기일마다 다른 조 경기가 열립니다.
  - 각 조 **1~3위는 8강 직행**, **4·5위는 같은 조끼리 플레이오프**(홈 앤드 어웨이, 4위가 2차전 홈)를 치러 이긴 팀이 8강에 오릅니다.
  - 8강 대진: A1-B플레이오프 승자, B2-A3, B1-A플레이오프 승자, A2-B3 (위 두 경기 승자끼리, 아래 두 경기 승자끼리 4강).
  - 8강·4강은 홈 앤드 어웨이 합계 점수로 가리고, 합계가 같으면 승부차기(전력 비율로 확률 결정). 결승은 5월 **중립 구장 단판**(홈 어드밴티지 없음)이며 비기면 승부차기.
  - 포스트시즌 경기는 조별 순위(승점)에는 들어가지 않습니다. 탈락한 뒤에도 남은 경기일은 진행되고, 우리 팀은 "경기 없음"으로 표시됩니다.
  - 순위표 탭 위쪽에 진행 방식과 포스트시즌 대진·합계 점수가 나옵니다.
- **조 추첨 (밸런스 추첨)**: 매 시즌 시작 때 각 팀의 상위 11명 평균 능력으로 전력 순위를 매기고, 비슷한 두 팀씩 9개 포트로 묶은 뒤 포트마다 한 팀은 A조, 한 팀은 B조로 무작위 배정합니다. 추첨식 화면에서 포트별로 한 팀씩 공개되고(결과 바로 보기 가능), 끝나면 두 조의 평균 전력이 나옵니다. 200시즌 시뮬레이션에서 두 조 평균 전력 차이는 최대 1.1(200점 만점)이었습니다.
- **최종 순위** (엔딩·평가 기준): 우승 1위, 준우승 2위, 4강 탈락 3~4위, 8강 탈락 5~8위, 플레이오프 탈락 9~10위, 조 6위 이하 11~18위(조 순위 → 승점 순).
- **운영진 목표**: S등급 4강 진출, A등급 8강 진출, B등급 플레이오프 진출, C등급 조 7위 이내
- **운영진 평가** (정규 시즌 14경기일 후, 결승 후): 위 목표 기준
  - 목표 달성 → 시설 향상 또는 보너스 중 선택
  - 목표보다 3계단 이상 위 → 둘 다
  - 목표에 크게 못 미침 → 경고 (사기 −10)
- **다크 모드**: 시작 화면 오른쪽 위나 게임 화면 위쪽의 `다크 모드` / `라이트 모드` 버튼으로 바로 바뀝니다. 선택은 저장되어 다음 실행 때도 유지됩니다.
- **하루 훈련 메시지**: `다음 날 ▶`을 누를 때마다 그날 한 일(팀 훈련 종류·강도), 훈련 수준·평균 체력 변화, 사기 변화와 선수단 반응(누가 돋보였는지, 지쳤는지, 분위기 등)이 소식에 나옵니다.
- **성장 속도**: 21세 이하 유망주는 시즌당 평균 약 +4, 22~25세는 약 +1.4 정도로 천천히 성장합니다(200점 만점).
- **시작 화면 · 감독 프로필**: 게임을 켜면 로고가 있는 시작 화면이 나오고, **새 게임 시작** → 감독 이름과 코칭 스타일 선택 → 구단 선택 순서로 진행합니다. 코칭 스타일은 5시즌 내내 적용됩니다.
  - 전략가: 경기 운영 상성에서 이기면 기대 득점 +40% (기본 +25%)
  - 지략가: 더 높은 등급 팀 상대로 득점 +7% · 실점 −7%
  - 체계구축가: 훈련 수준 상승 ×1.3 · 팀워크 +1.5%
  - 동기부여가: 시즌 시작 사기 +10 · 경기 후 사기 하락 40% 완화
  - 육성가: 선수 성장 확률 ×1.4
  - 실리주의자: 실점 −6% · 득점 −2%
  - 360시즌 시뮬레이션 기준 스타일이 없을 때보다 평균 0.4~0.9계단 오르며, 어느 하나가 압도적이지 않게 맞췄습니다.
- **경기 후 반응**: 경기가 끝나면 결과·상대 등급·멀티골 여부에 따라 팬 반응과 언론 기사가 라운드 결과 탭과 소식 탭에 나옵니다.
- **구단주 평가 (3경기마다)**: 최근 3경기 승점을 상대 등급 기준 기대 승점과 비교합니다. 같은 등급 상대는 경기당 1.4점, 한 등급 강한 상대는 0.95점, 한 등급 약한 상대는 1.85점을 기대합니다(예: S급이 S급 3팀에 2승 1패면 6점 > 4.2점 → 만족).
  - 대만족(기대 +2점 이상): 격려금 사기 +10, 그리고 특전 하나 선택
  - 만족(기대 이상): 특전 하나 선택 — 선수단 보너스(사기 +15) / 팀 워크숍(다음 3경기 팀워크 +3%) / 훈련 장비 지원(다음 3경기 성장 확률·훈련 효과 ×1.5) / MVP 특별 포상(최근 3경기 최다 득점자 체력 100·능력 +2)
  - 보통: 변화 없음 · 실망(기대 −2점 미만): 사기 −8
  - 자동 진행 중에는 첫 번째 특전이 자동 선택됩니다.
- **5시즌 커리어**: 시즌이 끝나면 다음 시즌으로 넘어갑니다. 모든 선수 나이 +1, 31세 이상은 능력이 떨어질 수 있고, 부상·체력·시즌 기록은 초기화, 사기는 절반으로 줄어듭니다. 성장한 능력과 시설 레벨, 우리 팀 전술은 그대로 이어집니다. 일정은 매 시즌 새로 짜고 날짜는 1년씩 밀립니다.
- **엔딩**: 시즌 중간에 경질되면 그 자리에서 끝납니다. 5시즌을 마치면 우승 횟수와 목표 달성 횟수에 따라 왕조의 설계자, 우승 감독, 믿음직한 장기 집권, 무난한 5년, 아쉬운 작별로 갈리고, 시즌별 커리어 기록이 함께 나옵니다.

## 선수 데이터 넣기 (data/players.csv)

`data/players.csv`를 엑셀이나 메모장으로 열어 한 줄에 선수 한 명씩 넣습니다.

```
구단,이름,포지션,나이,현재,최대,국적,키,몸무게,주발,보조포지션,스피드,슛,패스,드리블,수비,피지컬
코모 1907,홍길동,ST,23,156,170,대한민국,182,76,오른발,LW/CF
```

| 칸 | 설명 |
| --- | --- |
| 구단 | 18개 구단 이름 그대로 (띄어쓰기는 무시) |
| 이름 | 자유롭게. 쉼표가 들어가면 큰따옴표로 감쌉니다 |
| 포지션 | 세부 포지션: GK / CB·LB·RB·LWB·RWB (DF) / DM·CM·AM·LM·RM (MF) / ST·CF·LW·RW (FW). GK·DF·MF·FW만 쓰면 CB·CM·ST로 처리 |
| 나이 | 숫자. 어릴수록 시즌 중 잘 성장합니다 |
| 현재 | 1~200. 경기력 계산에 쓰입니다 |
| 최대 | 1~200. 시즌 중 성장할 수 있는 한계입니다 |
| 국적 | 선발 11명 중 같은 국적 선수 쌍마다 경기력 +0.15% (최대 +3%). 비워 두면 호흡 보너스 없음 |
| 키 | cm. 선발 필드 플레이어 평균 키가 상대보다 크면 공중볼 득점 기대 상승 (최대 ±6%, 공격 폭이 넓을수록 커짐) |
| 몸무게 | kg. 키와 함께 체격(BMI)을 계산하며, 체격이 큰 선수는 강한 압박 때 체력이 더 빨리 떨어집니다 |
| 스피드·슛·패스·드리블·수비·피지컬 | 선택. 비워 두면 포지션·능력·키·몸무게로 자동 계산합니다. 직접 넣으려면 6칸 모두 1~200 숫자로. 슛은 골 확률, 패스는 도움 확률에 반영됩니다 |
| 보조포지션 | 주 포지션 말고 뛸 수 있는 포지션을 `/`로 구분 (예: `LW/CF`). 그 자리에서 능력 97%로 뜁니다. 비워 두면 주 포지션만. 지금 값은 추정값이라 자유롭게 고치세요 |
| 주발 | 왼발 / 오른발 / 양발 (L·R·B도 가능). 측면 수비·미드필더 자리에 반대발이면 능력 -5%, 윙어는 인버티드라 감소 없음 |

국적·키·몸무게·주발은 비워 두면 기본값을 씁니다. `data/superleague_squads.xlsx`는 498명을 정리한 엑셀 통합본입니다.

- `#`으로 시작하는 줄은 무시됩니다.
- 선수를 하나도 넣지 않은 구단은 자동 생성됩니다. 일부만 넣으면 포지션별 최소 인원(GK 2·DF 6·MF 6·FW 4)이 모자란 만큼만 자동으로 채웁니다.
- 잘못된 줄은 건너뛰고, 게임 시작 때 몇 번째 줄이 왜 문제인지 알려 줍니다.
- 엑셀에서 "CSV UTF-8"로 저장해도, 그냥 "CSV"로 저장해도 됩니다.
- 선수단 탭에서 이름 옆 `*`은 자동 생성된 선수입니다.

**성장**: 매 라운드 선수마다 일정 확률로 현재 능력이 2 오릅니다 (최대 능력까지). 확률은 나이(21세 이하가 가장 높고 32세 이상은 성장 없음), 최대까지 남은 차이, 팀 훈련 수준에 따라 달라집니다.

## 웹 브라우저에서 실행

- `웹으로 실행.vbs`를 더블클릭하면 게임에 내장된 작은 웹 서버가 켜지고 브라우저(크롬 권장)가 `http://127.0.0.1:8765/`로 열립니다.
- 브라우저 안에서 [CheerpJ](https://cheerpj.com)(브라우저용 Java 실행기)가 **같은 SuperLeague.jar를 그대로** 실행합니다. 코드는 Java 그대로입니다.
- 처음 한 번은 Java 엔진을 내려받느라 30초 정도 걸리고, **인터넷 연결이 필요**합니다.
- 서버는 내 PC(127.0.0.1)에서만 접속됩니다. 작은 안내 창의 [확인]을 누르면 서버가 꺼집니다.
- 한글 글꼴은 PC의 맑은 고딕(`C:\Windows\Fonts\malgun.ttf`)을 브라우저 쪽 Java에 넘겨서 씁니다.

```
└── web/          WebServer(웹 버전용 로컬 서버)
```
