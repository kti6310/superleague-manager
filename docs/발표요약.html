01프로젝트 목표

Football Manager 같은 시뮬레이션의 재미를 살리되, 기존 게임과 다른 구조로 차별성을 만드는 것

구현

감독 시뮬레이션의 핵심 루프

훈련 → 전술 결정 → 경기 → 평가 → 성장으로 이어지는 흐름을 하루 단위 일정 위에서 구현

차별성

"슈퍼리그"라는 가상 무대

유럽 빅클럽 18팀이 모인 가상 리그에 미국식 디비전과 포스트시즌을 결합한 새로운 시즌 구조

설계

객체지향 구조와 검증

모델·엔진·게임 규칙·화면을 패키지로 분리하고, 수백 시즌 자동 시뮬레이션으로 밸런스 검증

02기존 게임과 다른 점

FM·FC 온라인 같은 게임에 없는, 이 프로젝트만의 요소

디비전 + 포스트시즌 시즌 구조

단일 리그 대신 9팀씩 두 조로 나눈 정규 시즌, 이어서 플레이오프·8강·4강·중립 구장 결승. 시즌 끝까지 긴장감 유지

전력 균형 조 추첨식

무작위지만 두 조의 전력이 비슷하도록 포트 방식으로 추첨하고, 추첨 과정을 애니메이션으로 보여 주는 이벤트

감독 코칭 스타일

전략가·지략가·체계구축가·동기부여가·육성가·실리주의자 6가지 중 선택. 각자 경기·훈련·사기에 실제 효과

구단주 평가와 특전

3경기마다 상대 전력을 고려한 기대 승점과 비교해 평가. 성과가 좋으면 사기·팀워크·훈련 성취도 특전 선택

07핵심 알고리즘

경기 엔진 — 포아송 득점 모델

두 팀의 경기력 비율로 기대 득점을 구하고, 전술 상성·팀 지시·역할·훈련·감독 스타일 보정을 곱한 뒤 포아송 분포로 실제 득점을 뽑습니다.

기대득점 = 기본값 × (홈 경기력 ÷ 원정 경기력)k × 전술 × 역할 × 훈련 × …

경기력 계산

선발 11명의 자리별 능력(포지션·주발 적합도 반영) 평균에 사기·훈련·시설·국적 호흡 보정을 더합니다.

경기력 = 선발 평균 × (1 + 사기 + 훈련 + 시설 + 호흡)

밸런스 조 추첨

상위 11명 평균 능력으로 18팀을 정렬해 2팀씩 9개 포트로 묶고, 포트 안에서 무작위로 A·B조 배정. 200시즌 실험에서 두 조 평균 전력 차이 최대 1.1점(200점 만점).

일정 생성 — 원형 순환 방식

라운드 로빈 원형 순환으로 리그 일정을 만들고, 9팀처럼 홀수일 때는 빈 자리를 넣어 쉬는 팀을 만듭니다. 홈·원정 연속을 줄이도록 균형 조정.

포스트시즌 대진

홈 앤드 어웨이 두 경기 합계로 승자 결정, 동률이면 전력 비율 확률의 승부차기. 승자에 따라 다음 단계 대진을 자동 생성.

구단주 평가 — 기대 승점

상대 등급 차이로 경기당 기대 승점(같은 등급 1.4점, 한 등급 차이 ±0.45점)을 정하고, 최근 3경기 실제 승점과 비교해 대만족·만족·보통·실망으로 판정.
