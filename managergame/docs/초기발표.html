SUPER LEAGUE MANAGER

Java로 만드는 축구 감독 시뮬레이션 게임

발표자: 김태일

01

어떤 게임인가요?

플레이어가 축구팀 감독이 되어 선수를 고르고, 전술을 정하고, 시즌을 치르는 게임

참고

Football Manager

직접 공을 차지 않고 감독으로서 결정만 내리는 시뮬레이션 장르

배경

가상의 "슈퍼리그"

유럽 빅클럽 18팀이 모인 가상 리그를 무대로 설정

기술

Java 17 + Swing

외부 라이브러리 없이 Java 표준 기능만으로 구현

02

프로젝트 목표

기존 축구 게임과 다른, 이 프로젝트만의 재미 만들기

  • 감독의 선택(전술·선수 기용)이 결과에 영향을 주는 경기 시뮬레이션
  • 기존 게임에 없는 새로운 리그 진행 방식으로 차별성 확보
  • 객체지향 설계로 데이터·경기 엔진·화면을 나눠 확장하기 쉬운 구조
03

지금까지 구현한 것

게임의 뼈대가 되는 데이터와 기본 기능

구단 · 선수 데이터

가상 구단 18팀, 선수 약 500명을 CSV 파일로 관리. 파일만 고치면 코드 수정 없이 반영

선수 능력치

능력치(최대 200), 포지션, 나이, 키·몸무게, 주발, 잠재력

기본 경기 시뮬레이션

두 팀 전력을 비교해 확률(포아송 분포)로 경기 결과와 득점자 결정

리그 일정 · 순위표

홈 앤드 어웨이 일정 자동 생성, 승점 기준 순위표, 기본 게임 화면

04

프로그램 구조

역할별로 패키지를 나눠 서로 영향을 덜 주도록 설계

data데이터

CSV에서 구단·선수 불러오기

model모델

선수 · 팀 · 포지션 · 전술

sim경기 엔진

경기 결과 · 득점자 계산

game시즌 규칙

일정 · 순위 · 시즌 진행

gui화면

Swing으로 보여 주기

05

앞으로의 계획 ① 경기

감독이 경기에 직접 개입하는 느낌 살리기

라이브 중계

문자 중계와 경기장 화면으로 경기 흐름을 실시간으로

전술판

포메이션과 자리별 역할을 드래그로 설정

교체 · 전술 변경

경기 중 선수 교체(3번, 최대 5명)와 전술 변경, 선수 체력 표시

05

앞으로의 계획 ② 리그 · 운영

기존 축구 게임과 차별화할 핵심 아이디어

차별성

디비전 + 포스트시즌

9팀씩 두 조 + 다른 조와도 경기(MLS 방식) → 플레이오프 · 8강 · 4강 · 중립 구장 결승

차별성

밸런스 조 추첨식

무작위지만 두 조 전력이 비슷하게 나뉘는 추첨

훈련 · 일정 · 평가

하루 단위 훈련, 3경기마다 구단주 평가와 보상, 팬·언론 반응

감독 커리어

감독 프로필과 코칭 스타일, 5시즌 커리어, 다크 모드 등 편의 기능
